## How it's built (all additive)
- **`src/weapons.js`**: one appended H3 block.
  - `PAIRINGS.push(...)` with ten rows. Each has a glyph, a hint and `d(l)` text with real numbers.
    `PAIR_BY_W` is rebuilt.
  - Fire-function wrappers suppress the parent attack: coil, mortar, die, phantom, moths, serpent,
    chalice, bloodNova and chandelierBurst.
  - A small engine has three run-scoped arrays: `h3S` (moths, pips, shards), `h3Z` (bombs,
    goblets/pools, the falling chandelier, wax, plague clouds, dice re-blasts) and `h3D` (dice in
    flight). It attaches by wrapping `tickPairings` and `drawPairings`, so there are no new core
    hooks for it.
  - `hurtPlayer` is wrapped for the heart's hit-burst.
- **Aura gate** (the Miasma's damage and draw are inline in core):
  - `src/core.js`: 2 one-line changes. `auraL` is 0 when evolved, and the second aura-cloud draw is
    gated.
  - `src/passives.js`: `auraRadius()` returns 0 when evolved.
- **`src/slot.js`**: ten PROJ_FX labels.
- **`src/ui.js`**: ten GLYPH_COL colors, each a distinct saturated hue.
- **Glyphs:** ⛓ 💣 🎲 🦈 🦋 🐍 🥂 ❣ 💎 ☣. All are common emoji or classic dingbats, with no rare
  blocks.
- **Determinism:** run-shaping rolls use `rng('evo')`. That covers the dice faces and landing
  scatter, the carpet heading jitter, the champagne ring radius and offset, the plague cloud
  targets, moth launch angles, pip spread and interest-coin scatter. Target choices are
  deterministic functions of the enemy array (densest pack, healthiest debtor, nearest chain hop).
  Sparkles, pitch and number pops stay on Math.random.
- **Martyr:** no H3 code writes to HP. The heart's "untouchable 1s" is invulnerability, not healing.
- **Persistence:** nothing new. The recipes ride C1's `IDX.pr`/`pm` and `LT.pairBy`, and no key changed.
- **GAME_DESIGN.md:** the PAIRINGS table gains the ten rows, the engine note mentions `h3S/h3Z/h3D`,
  and the inventory reads 20.

## Leftovers / for the next hand
- **Nine weapons still have no pairing:** orbit, scythe, pendulum, spark, seeker, bell, gramo,
  candelabra, guillotine.
  - Orbit, scythe and pendulum are inline in core's enemy loop and draw (plus fx.js). Pairing them
    needs a gate like the aura's in ~3 places each, or a ride-on-top design like the Ossuary's.
  - Spark is an on-hit effect with no fire function.
- **The Chain Gang moves enemy positions directly** for 0.35s (bosses are exempt). This is
  deterministic and harmless in tests. If a future enemy type relies on a fixed anchor (a turret,
  say), exempt it in `h3Chain`.
- **Black Death and Heart** look modest in the arena only because their parents (Miasma and Nova)
  already hit everything in a packed ring. In live fights they're ×2–×5.5. If the director wants
  them louder, raise the cloud damage to 450%/s or the burst to 1500%.
- The "you have married them all" announce now needs all 20.
